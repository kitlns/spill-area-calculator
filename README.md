# spill-area-calculator

Write a C++ program that:
  Prompts the user to enter:
  The rate of oil pumping in gallons per minute.
  The thickness of the oil layer in meters.
  The number of days the spill continues.
  For each day, calculate:
  Total minutes elapsed. Volume of oil spilled in gallons.
  Convert gallons to cubic meters using the constant 
  1 gallon = 0.00378541m3.
  
Compute the surface area covered in square meters by dividing volume by thickness.
  Convert square meters to square kilometers.
  Display the results for each day:
  Area covered by spilled oil (in square kilometers).
  Volume of oil on top of the water (in gallons).
  Ask the user if they want to calculate another spill and repeat if they answer yes.
